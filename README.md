# РИТМ

Telegram Mini App и бот для коротких спринтов привычек. Mini App отвечает за настройку и прогресс, бот — за спокойные напоминания, быстрые отметки, вечерний check-in и недельный отчёт.

## Возможности MVP

- защищённый вход через Telegram WebApp `initData`;
- один активный спринт на 14, 21 или 30 дней;
- до трёх направлений и привычек в спринте;
- расписание по дням недели и персональное время напоминания;
- идемпотентные отметки выполнения в Mini App и боте;
- перенос напоминания на два часа или на завтра;
- календарь и статистика только по запланированным выполнениям;
- коллекция идей «Хочу попробовать»;
- вечерний check-in, недельный отчёт и итог спринта;
- каталог из 16 направлений и 48 стартовых привычек, редактируемый в PostgreSQL.

## Локальный запуск

Требуются Node.js 22 и Docker.

```bash
cp .env.example .env
docker compose up -d db
npm install
npm run db:migrate
npm run db:seed
npm run dev
```

Mini App откроется на `http://localhost:5173`. В режиме разработки Telegram-авторизация заменяется тестовым пользователем из `.env`.

## Развёртывание

1. Направить DNS-запись домена на IP сервера.
2. Создать `.env` по образцу и заполнить `BOT_TOKEN`, `APP_DOMAIN` и надёжный `POSTGRES_PASSWORD`.
3. Выполнить `docker compose up -d --build`.
4. В BotFather назначить `https://APP_DOMAIN` как URL кнопки меню и Mini App.

Caddy автоматически выпустит HTTPS-сертификат. Миграции и безопасный повторный seed запускаются при старте контейнера приложения. Секреты не входят в образ и Git.

## Проверка

```bash
npm run typecheck
npm test
npm run build
curl https://APP_DOMAIN/api/health
```

Критические ограничения обеспечены базой данных: одна активная сессия на пользователя, уникальная отметка привычки на запланированную дату и уникальная отправка каждого типа уведомления.
